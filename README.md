# IPL Auction Simulator V2 — Playable Single Player

## Run
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use Live Server if available, or simply double-click `index.html`.
4. Select your franchise.
5. Select an auction set.
6. Click **NEW AUCTION**.
7. Use **BID** or **PASS**.

## Important
This version has the complete game logic in `app.js`. It does NOT require Node, npm, a database, or a backend.

### Gameplay
- 6 player sets
- AI bidding from the other 9 franchises
- 12-second auction clock
- Realistic bid increments
- AI fair-value limits to prevent absurd bids
- Purse management
- 25-player squad limit
- 8-player overseas limit
- Different AI spending personalities
- Sold/unsold results
- Live auction feed
- Squad and purse dashboards
- Set-completion report

Player ratings and valuations are simulation/game values, not official IPL ratings or official valuations.
